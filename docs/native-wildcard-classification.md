# Native wildcard classification

Eligible native scans compile the calibrated Python wildcard profiles once per
directory. HTTP workers normalize ASCII bodies, compare stable word patterns
and apply the existing similarity fallback in Rust. A proven negative crosses
the Python boundary as progress rather than a response object.

The shortcut requires GET, aggregated filtered progress callbacks and ordinary
filter policy. Detailed logging, unsupported explicit filters, redirects,
incomplete bodies, binary controls, non-ASCII bodies, encoded request paths and
profiles that cannot preserve Python text semantics retain Python classification.
Potential findings also retain the normal Python callback and report path.
All applicable prefix, suffix and default profiles retain their original roles.

## Ordered state

ASCII similarity indexes positions directly by byte value and omits popular
autojunk bytes before allocating their position lists. Unicode retains the
generic code-point implementation. Argument order and matching-block ties are
unchanged; the same exact differential tests cover both paths.

Response comparison is stateless and can run on different HTTP workers.
Auto-calibration observations are committed in input order as Python processes
the corresponding filtered ranges. Responses requiring fallback observe the
same state between those ranges. Pending observations are bounded by the active
wordlist chunk and discarded when a new scan begins; pause or cancellation does
not advance counters for a range that Python has not processed.

Native auto-calibration stores a SHA-256 digest of the complete normalized text
alongside its character length, status, media type and normalized redirect.
It does not retain response bodies. The thresholds and recording conditions
remain unchanged. Duplicate-result filtering retains its separate Python state;
wildcard negatives never reached that stage in the existing pipeline.

The extension API is 0.2.24 and requires rebuilding. Python request engines and
native callers without the complete classifier contract retain their existing
execution path. Tests compare compiled pattern decisions with the Python parser,
exercise shared state across native and Unicode fallback responses and isolate
state between targets.
